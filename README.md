A single fortune-cookie line for a crypto trader who has just been liquidated — oracular at first, then a rueful punchline about an empty wallet. The program writes the fortune to `entry.txt`, checked against the competition gate (one line, at most 20 words, 1–160 characters) before it writes anything.

## Run it

```sh
python3 main.py
```
